## Sobre o projeto

O **Curiti-go** é um guia digital feito por estudantes para apresentar Curitiba e ajudar visitantes a descobrir a cidade no próprio ritmo.

## O que você pode fazer

- Conhecer parques, museus, arquitetura e pontos turísticos.
- Explorar imagens por categoria e ampliar as fotos na galeria.
- Consultar roteiros para diferentes durações de passeio.
- Descobrir pratos e ingredientes da culinária regional.
- Salvar lugares favoritos neste navegador.
- Assistir a vídeos e ouvir faixas relacionadas à cidade.

## Como abrir

O projeto é um site estático e não precisa de instalação ou compilação.

1. Baixe ou clone o repositório.
2. Abra a pasta `Curiti-go`.
3. Abra `index.html` no navegador. Para desenvolvimento, você também pode usar a extensão Live Server do VS Code.

O Bootstrap e os ícones já estão incluídos localmente na pasta do projeto.

## Como funciona

Os favoritos são guardados no `localStorage` do navegador e ficam disponíveis apenas naquele navegador e dispositivo. O formulário de contato é demonstrativo: valida os campos, mas não envia mensagens para um servidor.
