## 🏙️ Sobre o projeto

O **Curiti-Go** é um site sobre Curitiba, criado como projeto da faculdade em parceria. A proposta é reunir e apresentar conteúdos sobre a cidade em uma experiência digital agradável e fácil de explorar.

## ✨ O que você encontra

- Conteúdo dedicado a Curitiba e suas atrações
- Uma página organizada para navegar e conhecer a cidade
- Um projeto feito em colaboração como parte de uma atividade acadêmica

## 🚀 Como acessar

Acesse o site pelo GitHub Pages, se estiver publicado. Caso contrário, clone este repositório e abra os arquivos do projeto localmente.

> As instruções específicas para executar o site podem ser adicionadas aqui conforme a estrutura e as tecnologias do projeto.
